Keeping the dashboard up to date

Two routines. The quick one refreshes views, subs, likes and comments for both channels. The Studio one adds the private numbers that explain why a video worked.

Dashboard: claude.ai/code/artifact/87305d9a…

Quick refresh Every day or two · 2 minutes

Updates both channels at once. Anyone with the sync page and an API key can do it.

  1. Open youtube-sync.htmlDouble-click it in the LarryVsLamps folder. The API key and both handles are already filled in from last time.
  2. Click Fetch both channelsWait for the log to say "Done".
  3. Click Copy to clipboard
  4. Open the dashboard and click Import dataTop right of the page.
  5. Paste into the "Or paste JSON" box, check both rows say the right channel, click ImportLarry should map to Channel A and Lamps to Channel B.
Each import adds one dot to the growth lines. Skip a week and the line just has a gap, nothing breaks.

Studio metrics Weekly · 5 minutes · each channel owner

Click-through rate and retention are private, so each of you exports your own channel from YouTube Studio on a computer.

  1. Go to studio.youtube.com and click Analytics
  2. Click Advanced modeTop right of the analytics page.
  3. Open the Content tabThe table should list your videos.
  4. Add these columns with + metricImpressions · Impressions click-through rate · Average view duration · Average percentage viewed. Only needed the first time; Studio remembers them.
  5. Set the date range to LifetimeTop right. This makes sure every video is included.
  6. Click the Export arrow and choose .csvA zip downloads. Unzip it to find Table data.csv.
  7. In the dashboard: Import data → YouTube Studio CSV tab → choose Table data.csv → ImportLeave the channel on "Detect from video IDs". Do the quick refresh first if the videos are not in the dashboard yet.
If you would rather not import it yourself, send the CSV to whoever runs the dashboard and they can import it for you.

What updates when

Quick refreshSubscribers, total views, every video's views, likes and comments, new uploads, growth lines, top videos, verdicts, Shorts vs long-form. Studio CSVImpressions, click-through rate, average view duration and percentage viewed. Fills in the "Packaging vs content" chart and the CTR and retention lines in each video's "why" panel.

The Studio import never overwrites view counts; the quick refresh never touches Studio numbers.
