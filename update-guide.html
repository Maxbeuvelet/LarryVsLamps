Keeping the dashboard up to date

Views and subscribers refresh themselves every morning. The only manual step is the weekly YouTube Studio export, which adds the private numbers that explain why a video worked.

Dashboard: maxbeuvelet.github.io/LarryVsLamps

Views, subs, likes, comments Automatic · every day at 6:00 AM

A scheduled job fetches both channels each morning and adds a point to the growth lines. Nothing to do.

Want fresh numbers right now? On github.com open the repository → Actions → Sync YouTube data → Run workflow. The dashboard updates a few minutes later.

Studio metrics Weekly · 5 minutes · each channel owner

Click-through rate and retention are private, so each of you exports your own channel from YouTube Studio on a computer.

  1. Go to studio.youtube.com and click Analytics
  2. Click Advanced modeTop right of the analytics page.
  3. Open the Content tabThe table should list your videos.
  4. Add these columns with + metricImpressions · Impressions click-through rate · Average view duration · Average percentage viewed. Only needed the first time; Studio remembers them.
  5. Set the date range to LifetimeTop right. This makes sure every video is included.
  6. Click the Export arrow and choose .csvA zip downloads. Unzip it to find Table data.csv.
  7. On the dashboard, click Upload Studio CSVPick your channel and the file. The numbers appear on your screen straight away, and the shared dashboard rebuilds within a few minutes.
First time only: the upload dialog asks for a GitHub token so it can save the file to the repository. The dialog walks you through creating one (about two minutes). It is remembered by your browser afterwards. A friend uploading their own channel must first be added as a collaborator on the repository.

What updates when

Daily jobSubscribers, total views, every video's views, likes and comments, new uploads, growth lines, top videos, verdicts, Shorts vs long-form. Studio CSVImpressions, click-through rate, average view duration and percentage viewed. Fills in the "Packaging vs content" chart and the CTR and retention lines in each video's "why" panel.

Studio CSVs never overwrite view counts; the daily job never touches Studio numbers.
